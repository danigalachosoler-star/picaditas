## Sobre el proyecto

Juego de ritmo/precisión con temática de fútbol para Roblox, con intención de monetizarlo. Primer juego de los dos desarrolladores en la plataforma. Alcance del MVP acotado, con techo de crecimiento amplio.

- **Repo:** https://github.com/danigalachosoler-star/picaditas
- **Stack:** Luau + Knit + Rojo + Wally + Rokit. Ver [[Por qué Luau y Knit]].
- **Reglas para Claude Code:** ver el archivo `CLAUDE.md` en la raíz del repo (no en el vault).
